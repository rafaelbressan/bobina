# Profile sources

- `mtp-ii-58.toml`: measured on paper by the bobina project (docs/printers/mtp-ii-58.md).
- Every profile with `measured = false`: generated by `tools/import_profiles.py` from
  [escpos-printer-db](https://github.com/receipt-print-hq/escpos-printer-db) by receipt-print-hq, licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Only model facts are taken (paper width in dots, dpi,
  columns of font A, native QR, code pages, cutter, barcode commands: the last three ⚠ not tested on paper, see
  docs/TESTED.md); the rest is bobina's conservative default (sizes up to 2x, safe mode for feeds after images, tear bar assumed at 5 mm) until someone measures the printer with
  `bobina calibrate tear` and `bobina calibrate feed`. Changes from the source: values reformatted as bobina TOML,
  conservative defaults added.
