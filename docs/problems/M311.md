# M311: unsafe template operation

- Severity: error (stops the job: nothing prints)
- Category: markup and data

## What to do

A counter format takes exactly one {:spec} ("{:d}", "A-{:03}"); other unsafe operations are refused.

In the terminal: `bobina help M311`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
