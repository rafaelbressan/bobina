# C102: more chart points than its width can show: neighbours averaged (aggregate=max: the largest)

- Severity: note (never stops the job, except --strict)
- Category: charts

## What to do

Nothing to fix: the drawing has 2 dots per point. last=N draws only the last N rows, aggregate=max keeps the peaks, and a wider chart (width=full) shows more.

In the terminal: `bobina help C102`. All charts codes and their meaning: [charts](charts.md); every category: [index](README.md).
