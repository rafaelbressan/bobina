# M205: the document's locale: is not a locale bobina knows (the machine's is used)

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Write a BCP 47 tag (pt-BR, en-US, fr-CA); the message suggests the closest one bobina knows.

In the terminal: `bobina help M205`. All codes: [index](README.md).
