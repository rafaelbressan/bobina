# M123: a code block, ::: line or link definition removed from a --data/--set value

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Nothing to fix when the value is data: it brings text, lists, quotes, tables and headings only. Code blocks, boxes and link definitions belong in the document: put the fences or ::: lines there, around {{ value | markdown }}.

In the terminal: `bobina help M123`. All codes: [index](README.md).
