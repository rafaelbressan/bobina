# M123: a ::: line or code fence in a --data/--set value printed as text

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Nothing to fix when the value is data: it prints as written. Boxes and code blocks belong in the document; put the ::: lines or the fences there, around {{ value | markdown }}.

In the terminal: `bobina help M123`. All codes: [index](README.md).
