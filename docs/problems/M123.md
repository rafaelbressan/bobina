# M123: code block, ::: or link definition removed (not the author's value)

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

A value that is not the author's own (data, or computed in the template) brings text, lists, quotes, tables and headings only. Code blocks, boxes and link definitions belong in the document or its front matter: put the fences or ::: lines around {{ value | markdown }}.

In the terminal: `bobina help M123`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
