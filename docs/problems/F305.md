# F305: font for this script not downloaded (off, or no network): letters print as boxes

- Severity: warning (never stops the job, except --strict)
- Category: fonts

## What to do

Get the font once, with the network: bobina fonts get NAME (the message names it; a document works too: bobina fonts get menu.bob.md). Then it prints offline.

In the terminal: `bobina help F305`. All codes: [index](README.md).
