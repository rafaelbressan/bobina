# M130: undefined variable printed as empty

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Give the variable a value: front matter, --set NAME=VALUE or a data column (the message lists them).

In the terminal: `bobina help M130`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
