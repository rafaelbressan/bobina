# M202: a value is not a number, or a date moved out of the calendar (printed as it is)

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Write the number with digits (24.90, 24,90 or R$ 24,90), or a smaller amount for add().

In the terminal: `bobina help M202`. All codes: [index](README.md).
