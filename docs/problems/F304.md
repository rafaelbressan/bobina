# F304: font for another script downloaded (once; used offline from then on)

- Severity: note (never stops the job, except --strict)
- Category: fonts

## What to do

Nothing to fix: the font is kept and used offline from now on (bobina fonts scripts). To never download: bobina config set font_downloads off.

In the terminal: `bobina help F304`. All codes: [index](README.md).
