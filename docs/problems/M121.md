# M121: raw block removed from a variable

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Raw blocks cannot come from a value that is not the author's own: put them in the document.

In the terminal: `bobina help M121`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
