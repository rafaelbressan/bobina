# E601: no AI to chat with: none found on this machine, or an unknown name

- Severity: error (stops the job: nothing prints)
- Category: errors

## What to do

Install or log in to one of the AIs the message lists (bobina ai list shows what this machine has), or use a name from it.

In the terminal: `bobina help E601`. All codes: [index](README.md).
