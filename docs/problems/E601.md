# E601: no AI found, or an unknown AI name

- Severity: error (stops the job: nothing prints)
- Category: errors

## What to do

Install or log in to one of the AIs the message lists (bobina ai list shows what this machine has), or use a name from it.

In the terminal: `bobina help E601`. All errors codes and their meaning: [errors](errors.md); every category: [index](README.md).
