# C110: rows with a label and no value at a chart's ends are left out (between values: a gap)

- Severity: note (never stops the job, except --strict)
- Category: charts

## What to do

Nothing to fix when they are a heading or a Total row; put a value under the label to draw it. A label with no value between rows with values is a gap in the line.

In the terminal: `bobina help C110`. All charts codes and their meaning: [charts](charts.md); every category: [index](README.md).
