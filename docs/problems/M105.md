# M105: a ::: block is never closed

- Severity: warning (never stops the job, except --strict)
- Category: markup and data

## What to do

Add a line of colons only (:::) where the block should end: the message lists what it holds now. A line of colons always closes the innermost open block.

In the terminal: `bobina help M105`. All codes: [index](README.md).
