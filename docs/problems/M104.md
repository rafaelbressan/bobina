# M104: a {…} after a table's title row: GitHub and Obsidian show that table as text

- Severity: note (never stops the job, except --strict)
- Category: markup and data

## What to do

It prints as written. To keep the table a table on GitHub and Obsidian, use style=header-invert on the table's {…} line, or the classes at the end of each title cell: | Item {.invert} | Price {.invert} |.

In the terminal: `bobina help M104`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
