# M155: a data source was renamed because a column has its name

- Severity: note (never stops the job, except --strict)
- Category: markup and data

## What to do

Nothing to fix: refer to the source by its new name (in the message).

In the terminal: `bobina help M155`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
