# C109: data= file not found, unreadable or outside the allowed folders: no rows from it

- Severity: warning (never stops the job, except --strict)
- Category: charts

## What to do

Check the path (relative to the document) and the format: CSV, TSV, XLSX or JSON. Under --sandbox the file must be next to the document or in image_dirs.

In the terminal: `bobina help C109`. All charts codes and their meaning: [charts](charts.md); every category: [index](README.md).
