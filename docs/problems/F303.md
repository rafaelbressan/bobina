# F303: size not supported natively, nearest native size used

- Severity: note (never stops the job, except --strict)
- Category: fonts

## What to do

Use a size the printer has natively (small, normal, large, title, huge), or a font size in px (raster).

Evidence: printed test N1 (docs/printers/mtp-ii-58.md).

In the terminal: `bobina help F303`. All codes: [index](README.md).
