# I109: what an image looks like (drawing or photo) and how it was printed; the other look is one class away

- Severity: note (never stops the job, except --strict)
- Category: images

## What to do

Nothing to do if it looks right. Otherwise add {.dither} (photo look) or {.threshold} (black and white); {threshold=60%} sets the cut (higher: more black).

In the terminal: `bobina help I109`. All codes: [index](README.md).
