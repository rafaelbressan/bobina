# M204: no locale for this machine: dates, numbers and money in English

- Severity: note (never stops the job, except --strict)
- Category: markup and data

## What to do

Set this machine's locale: bobina config set locale pt-BR (any BCP 47 tag), or write locale: in the document. Only a document's own locale: reads a typed 1.890 as a price; elsewhere it is printed as typed (M202).

In the terminal: `bobina help M204`. All codes: [index](README.md).
