# M204: no locale for this machine: dates, numbers and money in English

- Severity: note (never stops the job, except --strict)
- Category: markup and data

## What to do

Set this machine's locale: bobina config locale pt-BR (any BCP 47 tag), or write locale: in the document. Without one, a typed 1.890 is not read as a price (M202).

In the terminal: `bobina help M204`. All codes: [index](README.md).
