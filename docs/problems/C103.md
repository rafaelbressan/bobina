# C103: a chart value is not a number: its row is left out

- Severity: warning (never stops the job, except --strict)
- Category: charts

## What to do

Write the value as a number: 1234.5, R$ 1.234,50 with locale: pt-BR in the front matter, -20. A row with a word in a value column is left out; an empty cell is only a gap.

In the terminal: `bobina help C103`. All charts codes and their meaning: [charts](charts.md); every category: [index](README.md).
