# P402: the printer's name does not settle the profile (no match, or several widths): one was taken

- Severity: note (never stops the job, except --strict)
- Category: printer and paper

## What to do

Check the profile and its paper width: bobina profile list, then bobina init --profile ID (the message names the other one when the name fits two widths).

In the terminal: `bobina help P402`. All codes: [index](README.md).
