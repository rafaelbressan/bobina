# Q112: contact code not built: the network or its value is wrong (the code is left out, the rest prints, exit 9)

- Severity: warning (never stops the job, except --strict)
- Category: codes

## What to do

The message says what the network takes, with an example; bobina help contact lists every network. The rest prints and the exit code is 9 (--allow Q112: 0).

In the terminal: `bobina help Q112`. All codes: [index](README.md).
