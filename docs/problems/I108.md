# I108: image outside the document folder and image_dirs (--sandbox, MCP)

- Severity: warning (never stops the job, except --strict)
- Category: images

## What to do

Trust that folder? Add it to image_dirs in config.toml (image_dirs = ["~/Pictures"]), or move the image next to the document.

In the terminal: `bobina help I108`. All codes: [index](README.md).
