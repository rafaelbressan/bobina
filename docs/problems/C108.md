# C108: a table title names no column of its data= file (the file's columns are listed)

- Severity: warning (never stops the job, except --strict)
- Category: charts

## What to do

Write each title of the table as a column of the file (the message lists them); the first is the labels.

In the terminal: `bobina help C108`. All charts codes and their meaning: [charts](charts.md); every category: [index](README.md).
