# I111: crop= outside the image: cut to the image, or printed uncropped

- Severity: warning (never stops the job, except --strict)
- Category: images

## What to do

crop=x,y,width,height counts from the top-left corner, in pixels of the file (as an image viewer shows them) or percentages; keep x + width and y + height within the image's size the message gives.

In the terminal: `bobina help I111`. All images codes and their meaning: [images](images.md); every category: [index](README.md).
