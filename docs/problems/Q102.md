# Q102: QR error correction L reads with difficulty

- Severity: warning (never stops the job, except --strict)
- Category: codes

## What to do

Use error correction M or higher: ```qr {ecc=M}```.

Evidence: printed test N6 (docs/printers/mtp-ii-58.md).

In the terminal: `bobina help Q102`. All codes: [index](README.md).
