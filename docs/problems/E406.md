# E406: bobina init found no printer to set up

- Severity: error (stops the job: nothing prints)
- Category: errors

## What to do

Turn the printer on (Bluetooth: in range; USB: plugged in), or name it: bobina init --printer ADDRESS (or DEVICE), --command 'ssh HOST bobina send --yes -' for one on another machine.

In the terminal: `bobina help E406`. All codes: [index](README.md).
