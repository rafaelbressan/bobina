# P401: Bluetooth or USB printers cannot be looked for on this machine (the message says why)

- Severity: note (never stops the job, except --strict)
- Category: printer and paper

## What to do

Install or turn on what the message names, or set up another kind of printer: USB, a printer on another machine (ssh) or a file printer.

In the terminal: `bobina help P401`. All codes: [index](README.md).
