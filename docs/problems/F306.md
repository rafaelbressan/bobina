# F306: no font for the locale's script (none, or downloads off): English words, its formats

- Severity: note (never stops the job, except --strict)
- Category: fonts

## What to do

The dates and numbers are readable, in English with the country's formats (th-TH prints as en-TH). For the language itself: bobina fonts get LANG (or font_downloads = true in config.toml). Another locale: bobina config locale TAG, or locale: in the document.

In the terminal: `bobina help F306`. All codes: [index](README.md).
