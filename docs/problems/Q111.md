# Q111: payment code not built: an attribute is missing or invalid (the code is left out, the rest prints, exit 9)

- Severity: warning (never stops the job, except --strict)
- Category: codes

## What to do

The message names the attribute and gives a working example; bobina help pay lists every scheme. The rest prints and the exit code is 9 (--allow Q111: 0).

In the terminal: `bobina help Q111`. All codes: [index](README.md).
