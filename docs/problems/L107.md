# L107: table columns narrowed to fit the paper (widths scaled down, or too many columns)

- Severity: warning (never stops the job, except --strict)
- Category: layout

## What to do

Give the columns smaller width= (bobina check lists the width each got), leave one out, use a smaller font on the table's {…} line ({font=Terminus size=16px}), or turn the table: orientation=vertical.

In the terminal: `bobina help L107`. All layout codes and their meaning: [layout](layout.md); every category: [index](README.md).
