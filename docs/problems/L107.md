# L107: table column widths wider than the paper were scaled down

- Severity: warning (never stops the job, except --strict)
- Category: layout

## What to do

Give the columns smaller width= (bobina check lists the width each got), leave one out, or use a smaller font on the table's {…} line: {font=Terminus size=16px}.

In the terminal: `bobina help L107`. All codes: [index](README.md).
