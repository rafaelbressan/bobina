# L101: word longer than the line was split

- Severity: warning (never stops the job, except --strict)
- Category: layout

## What to do

Add a space or a hyphen to the long word, or use a smaller size; an address prints whole as a QR code (```qr```).

In the terminal: `bobina help L101`. All layout codes and their meaning: [layout](layout.md); every category: [index](README.md).
