# F202: untested font with strokes thinner than 2 dots

- Severity: warning (never stops the job, except --strict)
- Category: fonts

## What to do

Use a tested font (bobina fonts list), a bigger size or bold.

Evidence: printed test R4-01 (docs/printers/mtp-ii-58.md).

In the terminal: `bobina help F202`. All codes: [index](README.md).
