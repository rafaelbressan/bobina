# M106: four or more asterisks printed as asterisks, not bold (literal_asterisks)

- Severity: note (never stops the job, except --strict)
- Category: markup and data

## What to do

Nothing to fix when the asterisks are a decoration (****EXTRATO****). For bold, write **text**. To read every run as Markdown: literal_asterisks: false in the front matter, or bobina config set literal_asterisks off.

In the terminal: `bobina help M106`. All markup and data codes and their meaning: [markup and data](markup-and-data.md); every category: [index](README.md).
