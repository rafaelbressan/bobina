# F201: font below its tested minimum size

- Severity: warning (never stops the job, except --strict)
- Category: fonts

## What to do

Use the font at or above its tested size (bobina fonts list shows tested fonts and their minimum sizes).

Evidence: printed test F1, F2 (docs/printers/mtp-ii-58.md).

In the terminal: `bobina help F201`. All codes: [index](README.md).
