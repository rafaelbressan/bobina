# Q106: barcode type not supported by this printer

- Severity: warning (never stops the job, except --strict)
- Category: codes

## What to do

Use another type (code128 works on most printers); bobina draws unsupported types as an image.

Evidence: printed test N6 (docs/printers/mtp-ii-58.md).

In the terminal: `bobina help Q106`. All codes: [index](README.md).
