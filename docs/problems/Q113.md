# Q113: native QR with fixed modules: this QR printed as an image

- Severity: note (never stops the job, except --strict)
- Category: codes

## What to do

Nothing to fix: the image prints exactly. For the printer's own code, remove module= (its modules are always 5 dots) or put less data in it (it prints up to version 7). With render=native, module= and width= have no effect.

In the terminal: `bobina help Q113`. All codes: [index](README.md).
